# Vinyl Webshop (Frontend Eindproject)

Dit is mijn eindproject voor frontend, ontwikkeld als onderdeel van de MBO Software Developer opleiding bij Bit Academy. Het doel van dit project is het bouwen van een functionele en visueel aantrekkelijke webshop voor vinylplaten.

## Over het project
In deze webshop kunnen gebruikers door een collectie vinylplaten bladeren. De focus van dit project ligt op een strakke UI/UX-vormgeving, een duidelijke productweergave en interactieve functionaliteiten.

##  Gebruikte technieken
* **HTML5** 
* **Tailwind CSS** 
* **JavaScript**
